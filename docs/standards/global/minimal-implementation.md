## Minimal Implementation

### Build What You Need
Create only a function, a class or a method that a caller uses.

### Clear Purpose
Every method either has a caller or makes the code easier to read. Nothing
else earns a place.

### Delete Exploration Artifacts
Remove a helper that you wrote during development and left unused.

### No Future Stubs
Write no empty method, no placeholder function and no interface for a future
need.

### No Speculative Abstractions
Add a factory, a strategy or an adapter only for an immediate need.

### Review Before Commit
Confirm that every new method has a caller, or that it makes the code clearer,
before you call the task done.

### Unused Code Is Debt
Remove dead code at once. It confuses the next reader and it costs maintenance.
